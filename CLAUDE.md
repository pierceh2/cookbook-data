# Claude instructions

This repository stores a personal cookbook used by the iOS app. Each recipe lives in `recipes/<id>/` and follows the schema in `schema/recipe.schema.json`. `cookbook.json` is generated by the tooling and must not be hand-edited.

Common commands:

- `python tools/new_recipe.py "Title"`
- `python tools/new_recipe.py "Title" --wishlist`
- `python tools/render_sprite.py recipes/<id> --preview`
- `python tools/build_index.py`
- `python tools/validate.py`
- `make index`
- `make validate`

To add or edit a recipe, follow the Add-Recipe Workflow in `docs/ADD_RECIPE.md`.
